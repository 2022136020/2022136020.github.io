MetaGameFinder

IGDB 게임 데이터와 AI 자연어 검색으로 취향에 맞는 게임을 찾고, 찜하고, 리뷰로 기록하는 서비스

비공개 · 요청 시 공유

왜 만들었나

  • 게임 정보(평점, 장르, 플랫폼, 영상)가 여러 사이트에 흩어져 있어 비교가 번거로웠습니다.
  • "친구랑 가볍게 할 협동 게임"처럼 느낌으로 찾고 싶은데, 대부분 검색창은 제목만 받습니다.
  • 해 보고 싶은 게임을 모아 두고, 해 본 게임에 짧게 평을 남길 곳이 필요했습니다.

내가 한 일

1차(팀, 14주)에서는 모델과 검색·정렬 로직, DB, 화면 일부를 맡았습니다. 팀 프로젝트가 끝난 뒤 디자인이 아쉬워서 11월에 혼자 Figma 디자인을 다시 받아 전 화면을 갈아엎었고, 그 과정에서 번역과 날짜 표시 문제도 같이 고쳤습니다.

구조

AI 검색이 안 될 때

LLM이 JSON으로 답하지 않거나 호출이 실패하면 키워드 규칙으로 다시 해석합니다. 그래서 AI 키가 없어도 검색 자체는 됩니다.

인기순이 이상했던 것

처음엔 popularity 값이 전부 0이라 모르는 게임이 인기작으로 떴습니다. IGDB PopScore, 조회수, 다운로드 수 순서로 정렬 기준을 바꿨습니다.

리뉴얼하면서

  • 색과 여백을 CSS 변수로 묶어서 다크/라이트를 같은 변수로 전환
  • 게임 카드를 JSP 태그 파일 하나(gameCard.tag)로 만들어 모든 화면에서 공유
  • Nielsen 휴리스틱 평가를 3번 돌려서 고칠 목록을 뽑음
한국어인데 게임 소개가 영어로 나옴리뉴얼

원인Groq 키 만료(401), 대체 번역 API 하루 한도 초과(429), 번역 결과가 메모리에만 있어 재시작할 때마다 다시 번역하며 한도를 다 씀

해결번역 결과를 Translation_Cache 테이블에 저장. 키 오류와 일시 오류를 나눠 재시도, 500자 제한에 맞춰 문장 단위로 쪼갬, 한도 초과 안내문이 번역문으로 저장되지 않게 막음. 목록 카드는 저장된 번역만 쓰고, 없으면 게임 정보로 만든 요약을 보여 줌

날짜가 Wed Mar 18 16:19:40 KST 2026로 찍힘리뉴얼

원인JSTL fmt:formatDate가 로케일을 못 찾으면 toString()으로 출력

해결LocaleFilter에서 요청마다 JSTL 로케일을 현재 언어로 지정

상세 배너에 로고나 메뉴 화면이 나옴리뉴얼

원인IGDB 아트워크는 로고 위주가 많고, 어떤 게임은 첫 스크린샷이 세이브 화면

해결실제 게임 장면을 먼저 쓰고, 예외 게임은 hero-image.properties로 따로 지정

디자인 바꿨는데 예전 화면이 보임리뉴얼

원인브라우저 캐시

해결CSS·JS 주소에 버전 쿼리(?v=)를 붙임

홈 검색 결과가 안 나옴1차 팀

원인IGDB 호출이 실패하면 대체 검색 결과를 돌지 않음

해결이름 검색 경로를 정리하고 결과 처리 로직 수정

아직 못 한 것

  • 관리자 화면은 새 디자인과 다국어가 안 들어가 있습니다.
  • 개인정보처리방침, 이용약관, 가입 동의 절차가 없습니다. 휴리스틱 평가에서도 1순위로 나왔습니다.
  • 번역 품질과 속도는 여전히 외부 API 무료 한도에 묶여 있습니다.
처음엔 API가 잘 응답한다는 가정으로만 만들었는데, 키가 만료되거나 한도가 차는 일이 생각보다 자주 일어났습니다. 그래서 AI 검색이 안 되면 키워드 규칙으로 찾고, 번역이 안 되면 게임 정보로 만든 요약이라도 보여 주도록 바꿨습니다. 지금은 외부 API를 붙일 때 안 될 때 화면을 먼저 생각하는 편입니다.
